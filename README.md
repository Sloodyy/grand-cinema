# Le Grand Cinéma

Application web de réservation en ligne pour le cinéma Le Grand Cinéma.

## Technologies utilisées

- PHP 8.2
- Symfony 7.4
- MariaDB
- Twig
- HTML / CSS

## Organisation des branches

- `main` : version stable de l'application.
- `develop` : branche principale de développement.
- `feature/nom-fonctionnalite` : développement d'une nouvelle fonctionnalité.
- `fix/nom-correction` : correction d'un bug.
- `hotfix/nom-correction` : correction urgente sur la version stable.

## Workflow Git

Les nouvelles fonctionnalités sont développées sur des branches `feature/`, puis intégrées à `develop` après vérification.

La branche `main` conserve les versions stables et validées du projet.
